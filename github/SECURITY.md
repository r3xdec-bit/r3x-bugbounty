# Security Policy

## Responsible Usage & Legal Disclaimer

**R3X-BugBounty** is designed exclusively for authorized penetration testing, vulnerability assessment, bug bounty engagements with explicit scope permissions, and educational defensive research.

Unauthorized scanning, probing, or testing of computer networks without explicit, documented authorization from the asset owner is illegal and unethical. The authors, contributors, and maintainers assume no liability and are not responsible for any misuse or damage caused by this program.

## Reporting a Vulnerability in R3X-BugBounty

If you discover a security issue or vulnerability within the R3X-BugBounty framework itself:

1. **Do not create a public GitHub issue.**
2. Send an email to `security@r3xdec.local` with:
   - Detailed description of the vulnerability.
   - Proof of concept or reproduction steps.
   - Potential impact.
3. We will acknowledge receipt within 48 hours and work with you on a coordinated fix.
